E8-0 — the compiler→host ComponentContract for the store demo

produced by: just e8-contracts

One contract per DECLARATION, not per module: least authority, and a new
declaration leaves every existing contract byte-identical.

Note StorePage: it requires session.read — it builds a query key from
the session, so it reads the session to RENDER — and it does NOT
require database.write<Carts>, which its deferred handler performs.
Authority is recorded once, against the thing that performs it.

This note said rendering needs no authority and runs anywhere until
2026-08-10. It was true of a page whose current_session() call named
nothing. See docs/CORPUS.md C5 and tests/unresolved_provenance.rs.
