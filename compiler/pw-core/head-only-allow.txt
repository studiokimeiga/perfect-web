# Every `DeclaredType::constructor_head_only()` call site, with the reason it is
# legitimate. `tests/head_only.rs` fails on one that is not listed here.
#
# Architect ruling, 2026-08-08, after the third consumer in one day read a type's
# head and dropped its arguments:
#
#   Preserving generic arguments should be effortless. Discarding them should
#   require an explicit choice.
#
# `DeclaredType` makes `written()` the easy path and gives the discarding one an
# unpleasant name. This file is the audit of the discards that remain.
#
# Format: <file>:<function>  <category>  <reason>
#
# Categories:
#   paired      the arguments are passed alongside, so nothing is discarded
#   constructor the CONSTRUCTOR itself is the question, not what it carries

resolved.rs:resolve         constructor  the head is dispatched on — type parameter, primitive, builtin constructor, or declaration — and each branch then resolves `written.args()` in full. This is the one call site that reads the head in order to NOT discard the arguments: `List<MenuItem>` reaches the `List` branch and the branch resolves `MenuItem`. `resolution_reaches_every_argument_or_reports` is what says so, and `a_generic_differs_by_its_argument` is what would fail if the head became the answer

manifest.rs:split_result    constructor  split Result's complete value/error arguments into their distinct manifest roles; all other return types keep their complete written structure

values.rs:annotations       constructor  the parameter of a declaration the compiler generated for an owned table (track `row-ownership`) whose head is the platform's `capability.User` is not reported unresolved there: the head IS the question (is this the reader's handle the table gives?), and its argument is the owner field's own written type, which the row's record resolves and PW0367 holds to `capability.UserId`

bounded.rs:generated_help  constructor  identify the generated set form's top-level List parameter after an optional reader handle; its complete element type is then preserved with args().first().written() for the repair, and the reader is described separately
